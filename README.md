# 🏢 DimUp — Розумна система управління ОСББ (Smart OSBB)

Цифрова платформа для багатоквартирних будинків, яка об'єднує мешканців, правління ОСББ та сервісні служби в єдиній екосистемі за допомогою **Telegram-бота**, **Telegram WebApp (Mini App)** та **штучного інтелекту Google Gemini**.

---

## 🌟 Можливості системи

### 👤 Для мешканців:
- **🔧 Подання заявок з AI:** Опис проблеми текстом, голосовим повідомленням або фото. Нейромережа автоматично визначає категорію (сантехніка, електрика тощо), пріоритет (аварійний/звичайний) і дає корисні поради.
- **🤖 AI-Консьєрж 24/7:** Розумний помічник, який відповідає на будь-які запитання щодо правил будинку, графіків вивозу сміття та тарифів.
- **📱 Особистий кабінет (Mini App):** Перегляд поточного балансу квартири, історії нарахувань та онлайн-оплата.
- **📢 Оголошення та аварійні сповіщення:** Миттєве інформування про відключення води/світла та збори.
- **🗳 Опитування та голосування:** Участь у голосуваннях будинку прямо в Telegram.

### 🏢 Для правління та голови ОСББ:
- **📋 Диспетчерська заявок:** Управління статусами («В роботі», «Виконано», «Відхилено») та контроль виконання.
- **📢 Масові розсилки:** Оповіщення всіх мешканців будинку в 1 клік.
- **👥 Реєстр мешканців:** Перегляд бази квартир та контактів.

## 🛠 Технологічний стек

- **Мова:** Python 3.11+
- **Telegram Bot:** `aiogram 3.x` (сучасний асинхронний фреймворк)
- **Веб-сервер & WebApp:** `FastAPI`, `Uvicorn`, `Jinja2`, HTML5, CSS3, JavaScript
- **База даних:** `SQLAlchemy 2.0` (Async) + `SQLite` (aiosqlite) / `PostgreSQL`
- **Штучний інтелект:** `Google Gemini 1.5 Flash` (`google-generativeai`)

## 🚀 Швидкий запуск

### 1. Налаштування ключів (`.env`)
Відкрийте файл `.env` у корені проєкту та вкажіть ваші ключі:

```env
# Токен бота від @BotFather в Telegram
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Ключ Google Gemini (безкоштовно на https://aistudio.google.com/)
GEMINI_API_KEY=AIzaSyYourSecretGeminiApiKeyHere

# Ваш Telegram ID (щоб бот надавав права голови ОСББ)
ADMIN_TELEGRAM_ID=123456789
```

> **Де взяти Telegram ID?** Напишіть боту `@userinfobot` або `@myidbot` у Telegram.

### 2. Запуск проєкту

Просто двічі клікніть на файл **`run.bat`** або виконайте команду в терміналі:

```bash
run.bat
```

Після запуску:
- Telegram-бот почне приймати повідомлення.
- Веб-сервер WebApp буде доступний за адресою: `http://localhost:8000/webapp`
- База даних автоматично ініціалізується та наповниться тестовими даними (квартири 1-20, опитування, квитанції).

## 📁 Структура проєкту

```
бот ОСББ/
├── app/
│   ├── bot/                 # Telegram-бот
│   │   ├── handlers/        # Обробники подій (start, tickets, concierge, info, admin)
│   │   ├── keyboards/       # Кнопки та меню
│   │   └── states/          # Стан діалогів (FSM)
│   ├── webapp/              # Telegram WebApp (Mini App)
│   │   ├── static/          # CSS та JS стилі
│   │   ├── templates/       # HTML шаблони (Jinja2)
│   │   └── router.py        # FastAPI ендпоінти
│   ├── db/                  # База даних
│   │   ├── models.py        # Таблиці БД (User, Apartment, Ticket, Poll, Bill)
│   │   ├── session.py       # Підключення до бази
│   │   └── init_db.py       # Ініціалізація та демо-дані
│   ├── services/
│   │   └── ai_service.py    # Інтеграція з Google Gemini AI
│   ├── config.py            # Налаштування
│   └── main.py              # Головний файл запуску (FastAPI + aiogram)
├── .env                     # Конфігураційний файл
├── requirements.txt         # Залежності
├── run.bat                  # Файл швидкого запуску для Windows
└── README.md                # Документація
```
