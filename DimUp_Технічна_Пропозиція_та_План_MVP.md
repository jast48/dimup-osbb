# 🏠 DimUp — Розумна цифрова система для ОСББ
## Технічна пропозиція та план реалізації MVP (Етап 1)

---

### 📌 1. Резюме проєкту
**DimUp** — це цифрова екосистема для автоматизації управління багатоквартирним будинком, яка об'єднує мешканців, правління ОСББ та підрядників за допомогою штучного інтелекту.

**Мета першого етапу (MVP):**  
Запустити стабільний, швидкий та зручний **Telegram-комплекс (Бот + Mini App)** з інтегрованим **штучним інтелектом (Google Gemini AI)** для одного пілотного будинку з архітектурою, готовою до масштабування на тисячі будинків.

---

### 👥 2. Функціонал системи за ролями

#### 👤 Для мешканців:
1. **Швидка авторизація та особистий профіль:**
   * Прив'язка до квартири (номер, площа, кількість зареєстрованих осіб).
   * Безпечна верифікація правлінням.
2. **Розумне подання заявок (AI-Диспетчер):**
   * Можливість подати заявку текстом, **фото/відео** або **голосовим повідомленням**.
   * Автоматичне визначення категорії (сантехніка, електрика, ліфт, прибирання) та терміновості (звичайна / аварійна).
   * Відстеження статусу заявки («Прийнято», «В роботі», «Виконано»).
3. **Фінанси та нарахування (Mini App):**
   * Перегляд балансу, щомісячних квитанцій та історії платежів.
   * Кнопка швидкої оплати за реквізитами або через платіжний шлюз.
4. **Голосування та опитування (Mini App):**
   * Участь у загальних опитуваннях та легітимних голосуваннях будинку в зручному графічному інтерфейсі.
5. **Оголошення та аварійні сповіщення:**
   * Миттєві push-повідомлення про відключення води/світла, ремонтні роботи або збори.
6. **Документи та контакти:**
   * База документів (Статут, тарифи, звіти ревізійної комісії) з можливістю швидкого пошуку.
   * Контакти правління, аварійних служб та майстрів.
7. **🤖 AI-Консьєрж 24/7:**
   * Цілодобові відповіді на будь-які питання щодо будинку, графіків, тарифів та правил проживання.

---

#### 🏢 Для правління та голови ОСББ:
1. **Диспетчерська заявок:**
   * Зручний список усіх звернень мешканців із фільтрами за статусом, терміновістю та категорією.
   * Призначення відповідального виконавця/підрядника в 1 клік.
   * Контроль термінів та фотозвітів виконаних робіт.
2. **База мешканців та квартир:**
   * Реєстр власників та орендарів, статус верифікації, контактні дані.
3. **Фінансовий контроль:**
   * Завантаження нарахувань (Excel / CSV / 1C) та автоматичне формування квитанцій для жителів.
   * Звіти по заборгованостях та аналітика оплат.
4. **Система масових розсилок:**
   * Створення адресних розсилок (для всього будинку, для окремого під'їзду чи боржників).
   * 🤖 **AI-копірайтер**: допомога голові ОСББ у швидкому формуванні грамотних та ввічливих текстів оголошень.
5. **Створення голосувань та аналітика:**
   * Конструктор опитувань із вибором варіантів, таймером завершення та автоматичним підрахунком голосів.

---

#### 🔧 Для майстрів та підрядників:
* Отримання сповіщень про нові призначені заявки.
* Можливість зміни статусу роботи та прикріплення фото «До / Після».

### 🤖 3. Архітектура штучного інтелекту (Google Gemini AI)

Штучний інтелект у DimUp вбудований у всі ключові процеси:
* **Мультимодальне розпізнавання:** розпізнає фото зламаного обладнання, розшифровує голосові повідомлення мешканців без потреби у сторонніх сервісах.
* **Автокласифікація:** визначає профіль майстра (сантехнік / електрик / покрівельник) та ступінь аварійності.
* **RAG-пошук по базі знань будинку:** знаходить відповіді на питання мешканців прямо з офіційних протоколів та статуту ОСББ.

---

### 🛠 4. Технологічний стек
* **Бекенд:** Python (FastAPI + aiogram 3) — сучасний, асинхронний, високошвидкісний рушій.
* **База даних:** PostgreSQL + SQLAlchemy — надійне збереження даних, підтримка транзакцій та масштабування.
* **Штучний інтелект:** Google Gemini 1.5 Flash API (мультимодальний аналіз тексту, аудіо, фото).
* **Фронтенд (Mini App):** HTML5, CSS3, JavaScript (Telegram WebApp API) — сучасний інтерфейс без потреби завантажувати сторонні додатки з магазинів на етапі MVP.

### 📅 5. План та етапи розробки (Roadmap MVP)

| Етап | Опис робіт | Результат |
| :--- | :--- | :--- |
| **Етап 1: Проєктування та фундамент** | Налаштування БД, моделі користувачів/квартир, базова авторизація в Telegram-боті. | Працюючий каркас, меню бота, реєстрація мешканців. |
| **Етап 2: Розумний модуль заявок + AI** | Інтеграція Google Gemini, приймання тексту/фото/голосу, авто-маршрутизація заявок. | Мешканець подає заявку → AI її класифікує → вона потрапляє в базу. |
| **Етап 3: Telegram WebApp (Mini App)** | Інтерфейс особистого кабінету, перегляд нарахувань, опитувань та документів. | Зручний графічний інтерфейс всередині Telegram. |
| **Етап 4: Панель голови ОСББ та сповіщення** | Модерація заявок, розсилки повідомлень, завантаження нарахувань, опитування. | Повний адміністративний контроль для правління. |
| **Етап 5: Тестування та реліз пілота** | Комплексне тестування з реальними сценаріями, оптимізація швидкості, здача проєкту. | Готовий до експлуатації продукт для пілотного будинку. |
